# lookimportant

**Look Important** is a puzzle-box desk toy. You sit at an engineer's workbench
with a pegboard behind it, and everything you can see clicks, flicks,
hums or swings. Somewhere in there is a secret drawer. See [intent.md](intent.md)
for the design intent and [changelog.md](changelog.md) for what changed.

There are no instructions or settings in the game. You point and click, and
moving the cursor towards the screen edges turns your head.

## Layout

| Path | What |
|---|---|
| `blender/build_scene.py` | Builds every model **and** the layout procedurally, then exports `game/Assets/Art/Models/WorkbenchScene.fbx`. Blender is the source of truth for geometry, pivots, and where lights and the camera sit (`*_Point` / `*_Target` empties). |
| `blender/workbench.blend` | Saved output of the script, for poking at in Blender. Regenerate rather than hand-edit. |
| `blender/render_preview.py` | Cycles render from the player's camera, to check layout before Unity. |
| `game/` | Unity 6.3 LTS project (URP, Input System). |
| `game/Assets/Art/materials.json` | Shared palette: Blender previews and Unity URP materials are both generated from it. |
| `game/Assets/Editor/SceneBuilder.cs` | Turns the FBX into `Assets/Scenes/Workbench.unity`: behaviours, colliders, lights, audio, post-processing. The scene is generated, so hand edits are lost on rebuild. |
| `game/Assets/Scripts/` | Runtime: interaction, camera, props, and `WorkbenchCircuit` (placeholder wiring). |
| `tools/` | Asset generators and build helpers (below). |
| `Builds/` | Player output (git-ignored). |

## Pipeline

```sh
tools/install-tools.sh                 # Blender + Unity editor/modules on a fresh machine
tools/activate-unity.sh                # once per machine: Unity Personal via your Unity ID (prompts)

uv run tools/fetch_textures.py         # CC0 textures from Poly Haven -> Assets/Art/Textures
uv run tools/make_dial_textures.py     # gauge and selector faces
uv run tools/make_sounds.py            # synthesised sound effects -> Assets/Art/Audio
blender -b -P blender/build_scene.py   # models + layout -> WorkbenchScene.fbx

tools/build.sh                         # rebuild scene, build Linux + Windows + WebGL into Builds/
tools/build.sh linux                   # one target
tools/build.sh --scene-only            # just regenerate the Unity scene
tools/capture.sh shot.png live         # headless screenshot of the Linux build (rest|live|dark|hover)
tools/perf.sh 1440 900 10              # frame times on this machine's real GPU (headless Weston)
tportless lookimportant uv run tools/serve_webgl.py   # WebGL preview on the tailnet
```

Generated assets (FBX, textures, audio) are committed, so a clone builds without
re-running the generators.

The Linux editor encodes WebGL audio with `ffmpeg`; without it the clips silently
import as plain files and the scene build stops with "missing clip".

Unity needs a Personal licence activated **on the machine doing the build**.
A `Unity_lic.ulf` copied from another computer is rejected because its machine
bindings don't match. Use `tools/activate-unity.sh` instead.

## Alpha 1 bench (placeholder wiring)

- **Knife switch** (pegboard, right): mains. Nothing on the bench is live until its blades are seated.
- **Toggles 1-3** (orange box): each lights its pilot lamp when live.
- **Selector** (olive box): sets the gauge's base reading. Each lit lamp adds load.
- **Big red button**: overload. Holding it slams the gauge into the red and the mains buzz.
- **Gauge**: tap the glass to knock the needle.
- **Desk lamp**: click to switch it.
- **Tools, padlock, mug, screwdrivers**: fidget toys. They swing, rattle and clink. The padlock stays locked for now.

## Performance

The reference is this build machine's Intel HD Graphics 6000 (a 2015 laptop iGPU),
measured with `tools/perf.sh` (vsync off, everything switched on):

| Resolution | Frame time (avg / p95) |
|---|---|
| 1440x900 | 13.8 / 14.7 ms |
| 1920x1080 | 20.8 / 21.8 ms (the game drops render scale to 0.7 by itself, about 14 ms) |

What each feature cost at 1440x900 decided the defaults: SSAO 10 ms (4.6 ms even at
its cheapest), MSAA x4 6 ms, SMAA 4.7 ms, FXAA 1.2 ms, ceiling-light shadows 1.6 ms,
soft shadows 1.3 ms, full-res bloom 0.5 ms. Re-run the same comparisons with flags like
`tools/perf.sh 1440 900 6 live -perf-nossao -perf-aa fxaa`.
