# Intent: Game that installs and runs locally
Author: Matt Ashby. Status: draft.
## Opportunity
Build a game which is a Japanese-puzzle-box style mixture of fidget-spinner attention holding, idle game in a casual format. It holds the users attention because the user is interacting with objects that make a sound or change the state of something else in the field of view.
## Proposal
Engineers workbench, with a pegboard backing. Aperture Desk Job vibe. Objects displayed on the bench and peg board. Can interact with the objects. Some switches, some toggles, some of the switches change the behaviour of other objects. Unlocking locks with switches and object states progresses to eventually opening a secret draw on the board which isn't visible in the original field of view. All switches and objects need to be in the correct state for the end game sequence to fire.
## Objective
Unlock a secret drawer. This isn't obvious when starting the game.
## Constraints
No instructions for the player/user. No options to adjust settings. Minimal software installed locally, will need to download what is needed; engine install size is exempt. Performance must be optimised for the engine in use. No money able to be spent on licensing game engines. No assets or textures will be purchased, these will need to be downloaded or created.
## Decisions
Engine: Unity Personal.
